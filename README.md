# 🤖 AI Crypto Levels Scanner (Advanced Terminal)

**Полноценный десктопный терминал для поиска и анализа сильных уровней поддержки/сопротивления на криптобиржах.**

Проект представляет собой высокотехнологичное приложение, объединяющее нейросетевой анализ (Deep Learning) с классическими методами кластеризации данных.

## 🧠 Ключевые технологии и архитектура
*   **Deep Learning:** Нейросеть на PyTorch (LSTM + Self-Attention) для прогнозирования значимых ценовых уровней.
*   **Кластеризация:** Алгоритм DBSCAN (Scikit-learn) для группировки близких уровней и отсечения рыночного шума.
*   **Встроенный бэктестинг:** Модуль автоматической проверки уровней на исторических данных с расчетом винрейта (Success Rate).
*   **Многопоточность:** Вынос тяжелых вычислений в QThread (PyQt5), обеспечивающий плавную работу интерфейса.
*   **Визуализация:** Интерактивные свечные графики и графики объемов (pyqtgraph).
*   **Интеграция с биржей:** Прямое подключение к Binance через CCXT для получения данных в реальном времени.

## ⚙️ Функционал
*   Сканирование топ-200 пар (USDT) в режиме реального времени.
*   Автоматическое определение типов уровней (Support/Resistance).
*   Отображение силы уровня и процента успешных реакций.
*   Интерактивный график с возможностью клика по уровню для детального анализа.
